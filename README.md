# IFFT · 智能填表工具

给影石校园创作者用的作品登记小工具：在抖音 / 小红书作品页**点一下提取**，
回到飞书表单页**再点一下填充**，原本三四分钟的手工活变成十几秒。

## 一、先选一种装法

| 装法 | 适合谁 | 要不要装 Node | 推荐度 |
|---|---|---|---|
| **浏览器扩展** | 绝大多数人 | 不要 | ⭐ 推荐 |
| **油猴脚本** | 已经在用 Tampermonkey 的人 | 不要 | ⭐ 推荐 |
| **桌面应用** | 需要内置浏览器、批量提交的人 | 要（或用安装包） | 按需 |

三种装法功能一致，挑一个就行，**不要同时装两种**。

---

## 二、装法 A：浏览器扩展（推荐）

支持 Chrome、Edge、Brave 等 Chromium 内核浏览器。

1. 打开右侧 **Releases**，下载 `IFFT-Extension-<版本号>.zip`，解压到任意文件夹
   （解压后文件夹里应当能看到 `manifest.json`）
2. 浏览器地址栏输入 `chrome://extensions/` 回车（Edge 是 `edge://extensions/`）
3. 打开右上角的 **开发者模式** 开关
4. 点 **加载已解压的扩展程序**，选中刚才解压出来的 `ext-ifft` 文件夹

装好后右上角会出现拼图图标 🧩，点它把 **IFFT** 固定到工具栏，之后一眼就能找到。

> **注意**：用「加载已解压的扩展程序」方式安装的扩展，浏览器重启时会提示「请禁用开发者模式扩展」。
> 这是浏览器对所有未上架扩展的统一提示，点「保留」即可，不是报错。

---

## 三、装法 B：油猴脚本

1. 浏览器先装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开本仓库的 [`web/ifft.user.js`](./web/ifft.user.js)，点右上角的 **Raw**
3. Tampermonkey 会自动识别并弹出安装页，点 **安装** 即可

---

## 四、装法 C：桌面应用（Windows）

1. 打开右侧 **Releases**，下载 `IFFT-<版本号>-win-x64-release.exe`
2. 双击安装
3. 首次启动需要激活，按界面提示操作（约 1 分钟）

## 五、用起来（五步）

### 第 1 步：在自己的浏览器里登录

用你平常的浏览器登录**抖音**和**小红书**。扩展直接复用已有登录态，
**不需要**在工具里重新登录。

### 第 2 步：填一次预设

点工具栏的 IFFT 图标打开面板 → **预设**，把真实姓名、身份、主理人姓名、
教育阶段、学校、抖音昵称、小红书昵称填一遍 → **保存**。

> 昵称要填**纯昵称文本**，不要带 `@`。
> 填一次就一直有效；换电脑时用「导出配置 / 导入配置」搬家。

### 第 3 步：校准字段（只需做一次）

打开飞书表单页 → 点面板里的 **扫描控件** → 看看有没有「未自动匹配」的字段，
在对应下拉里手工指定 → **保存映射**。

映射会记住，以后打开同一个表单自动带出。

### 第 4 步：日常录入

1. 打开你的作品页（抖音 / 小红书）
2. 点面板里的 **提取本页作品**
3. 切到飞书表单页，点 **填充**
4. 看一眼报告：全部「已填 / 跳过」才能点 **核对后提交**

### 第 5 步：24 小时后补点赞数

重新打开那条作品页 → **提取本页作品** → 回表单页点 **填充**。
工具会认出这是回填记录，把点赞数写进「24 小时后点赞数」。

## 六、常见问题

| 现象 | 怎么办 |
|---|---|
| 装完浏览器上看不到图标 | 点右上角拼图图标 🧩，把 IFFT 固定到工具栏 |
| 某个下拉填不进去 | 报告里会列出**当前可见的选项**，把预设里的值改成和选项一致 |
| 「核对后提交」按钮不出现 | 有字段没填成功——这是保护机制。看报告里哪一项是「失败」，按提示改 |
| 使用机型识别不出来 | 在提取面板的「使用机型」下拉里手工指定一次 |
| 24 小时提醒没弹 | 浏览器把通知关了就收不到。打开作品页手动提取一次同样有效 |
| 换电脑要重新填预设吗 | 不用。旧环境「导出配置」，新环境「导入配置」，一个文件搞定 |
